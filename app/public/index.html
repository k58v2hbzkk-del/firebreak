    One brake for every chain

    No single chain can check a bridge's promise, because each chain only sees half of it. FirebreakReactive on Reactive Lasna sees both halves: every lock, mint, burn and release lands in one ledger.

    The lending pool lets new bridged collateral settle for 2 blocks before it can back a loan. That window is only safe because Reactive Omni's ~1 second blocks let Firebreak decide inside it.
