How it works

No chain can see a bridge's whole promise.
Reactive can.

01

Both halves, one ledger

FirebreakReactive on Reactive Lasna subscribes to the vault on Unichain and the minter on Base. Every lock, mint, burn and release lands in one set of books.

02

Check every event

A mint must match a lock of the same id and amount. A release must match a burn. Supply can never pass backing. A forged message breaks one of these at once.

03

Halt every chain at once

On a breach it requests callbacks to a FirebreakGuard on each chain in the same reactive transaction. The guards halt the minter, the lending pool and the vault.

04

Humans decide when it's safe

A machine can pull the brake; only governance can release it. Repaying loans and withdrawing debt-free collateral keep working while halted.

Why it needs Reactive Omni

The lending pool lets new bridged collateral settle for 2 blocks (about 4 seconds) before it can back a loan. That window is only safe because Omni's ~1 second blocks and instant finality let Firebreak decide inside it. On a 7-second network, the window would have to be several times longer for every honest user.
